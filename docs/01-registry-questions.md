# ① 등기부 읽기 도우미: 질문 목록과 점수 규칙

> 상태: **초안 (팀 검토 전)**. 점수는 팀이 조정할 수 있는 값이야. 바꾸면 Decision Log에 이유를 남기자.
> 결과 화면에는 반드시 "참고용이며 법적 판단이 아닙니다. 계약 전 공인중개사·전문가에게 확인하세요." 문구를 넣는다.

## 0. 사용자가 먼저 알아야 할 것 (화면 첫 안내)

| 용어 | 쉬운 말 |
|---|---|
| 등기부등본 | 집의 "이력서". 누가 주인인지, 이 집에 빚이 걸려 있는지가 적혀 있음. 인터넷등기소에서 누구나 발급 가능 |
| 표제부 | 집 소개란. 주소, 크기, 용도 |
| 갑구 | **주인** 이야기. 누가 언제 샀는지, 주인 재산에 문제(압류 등)가 있는지 |
| 을구 | **빚** 이야기. 이 집을 담보로 빌린 돈(근저당권), 다른 세입자의 권리 |
| 빨간 줄(취소선) | 이미 지워진(말소된) 기록. **빨간 줄이 없는 것만** 현재 살아 있는 기록이야 |
| 건축물대장 | 건물의 "건강검진표". 불법 증축(위반건축물) 여부가 여기 나옴. 정부24에서 무료 |

## 1. 질문 목록

답은 모두 `예 / 아니오 / 모르겠어요` 3지선다. **"모르겠어요"는 위험 쪽으로 계산**하고, "중개사에게 확인하세요" 안내를 붙인다 (모르는 걸 안전하다고 보면 안 되니까).
화면·seed 데이터에 넣을 때는 설명을 해요체로 바꾼다 ("~있어" → "~있어요").

| 코드 | 위치 | 질문 | 위험한 답 | 점수 | 쉬운 설명 |
|---|---|---|---|---|---|
| `T1_ADDRESS` | 표제부 | 표제부의 주소(동·호수까지)가 계약할 집 주소와 똑같나요? | 아니오 | +60 | 다른 집 등기부를 보고 있을 수 있어. 동·호수까지 맞는 등기부로 다시 발급해야 해 |
| `T2_USAGE` | 표제부 | 건물 용도에 아파트·다세대주택·연립주택·다가구주택·단독주택 중 하나가 적혀 있나요? | 아니오 | +20 | "근린생활시설", "사무소"면 원래 사람이 사는 집이 아니야. 전세보증보험 가입이 거절될 수 있어 |
| `A1_OWNER` | 갑구 | 갑구 맨 아래 소유자 이름이 계약하러 나온 집주인 이름과 같나요? | 아니오 | +30 | 주인이 아닌 사람과 계약하면 보증금을 못 돌려받을 수 있어. 대리인이면 위임장과 인감증명서가 꼭 필요해 |
| `A2_RECENT_OWNER` | 갑구 | 소유권이 바뀐 날짜(접수일)가 최근 3개월 안인가요? | 예 | +10 | 집을 사자마자 전세를 놓는 경우 "바지 집주인" 수법일 수 있어. 꼭 나쁜 건 아니지만 한 번 더 확인 |
| `A3_TRUST` | 갑구 | 갑구에 "신탁"이라는 단어가 (빨간 줄 없이) 있나요? | 예 | +30 | 집의 진짜 주인이 신탁회사라는 뜻이야. 신탁회사 동의 없이 한 계약은 효력이 없을 수 있어 |
| `A4_SEIZURE` | 갑구 | "압류, 가압류, 가처분, 가등기, 경매개시결정" 중 하나라도 (빨간 줄 없이) 있나요? | 예 | +60 | 집주인이 빚 문제로 이 집을 빼앗기기 직전이거나, 소유권 다툼이 있다는 신호야. 계약하지 않는 게 좋아 |
| `B1_MORTGAGE` | 을구 | 을구에 "근저당권"이 (빨간 줄 없이) 있나요? | 예 → 채권최고액 입력 | 계산 (모르겠어요: +10) | 이 집을 담보로 은행에서 돈을 빌렸다는 뜻. 그 자체로 불법은 아니지만, 금액이 크면 위험 (아래 2절 계산) |
| `B2_LEASE_REG` | 을구 | 을구에 "주택임차권"(임차권등기)이 있나요? | 예 | +60 | **이전 세입자가 보증금을 못 돌려받았다**는 기록이야. 아주 강한 위험 신호 |
| `B3_JEONSE_RIGHT` | 을구 | 을구에 다른 사람 이름의 "전세권"이 (빨간 줄 없이) 있나요? | 예 | +20 | 이전 세입자의 권리가 아직 정리되지 않았어. 나보다 먼저 돈을 받아 갈 사람이 있다는 뜻 |
| `R1_VIOLATION` | 건축물대장 | 건축물대장 맨 위에 "위반건축물" 표시가 있나요? | 예 | +20 | 불법으로 고치거나 늘린 건물이야. 전세보증보험·전세대출이 막힐 수 있어 |

### 1.1 OCR 확인 기준 (개정 초안)

문서가 입력한 주소와 같은 집의 것인지 확인한 뒤 아래 근거를 사용한다. 문서가 없거나 일부 페이지가 빠졌거나, 대상·말소 여부·내용을 확인할 수 없으면 해당 질문을 사용자에게 보여준다. 권리가 없다는 답은 관련 구역을 충분히 확인한 경우에만 채운다. **OCR 미확인은 사용자 선택값 `UNKNOWN`과 구분한다.** 질문 코드와 점수표는 기존 기준을 사용한다.

| 질문 코드 | 확인 근거와 보완 조건 |
|---|---|
| `T1_ADDRESS` | 입력 주소와 등기부 표제부의 주소·동·호수를 비교한다. 주소가 다르면 맞는 서류를 다시 확인하도록 안내한다. |
| `T2_USAGE` | 표제부 또는 같은 집의 건축물대장에 적힌 용도를 확인한다. 문서 간 용도가 다르거나 해석하기 어려우면 질문으로 넘긴다. |
| `A1_OWNER` | 갑구에서 소유자 이름을 읽을 수 있다. 계약 상대방과 같은 사람인지는 비교 근거가 없으면 직접 확인받는다. |
| `A2_RECENT_OWNER` | 갑구의 최신 소유권 변경 접수일을 확인한다. 접수일이나 해당 등기를 식별할 수 없으면 보완한다. |
| `A3_TRUST`, `A4_SEIZURE` | 갑구에서 유효한 신탁·압류 등 해당 기록을 찾는다. 말소 여부가 불명확하면 해당 질문을 남긴다. |
| `B1_MORTGAGE` | 을구에서 유효한 근저당권과 채권최고액 합계를 확인한다. 존재는 확인했으나 합계가 불명확하면 금액만 입력받는다. |
| `B2_LEASE_REG`, `B3_JEONSE_RIGHT` | 을구의 유효한 주택임차권·전세권 기록을 확인한다. 권리 상태나 질문에 필요한 대상이 불명확하면 보완한다. |
| `R1_VIOLATION` | 건축물대장의 위반건축물 표시를 확인한다. 표시 영역이 누락됐거나 판독이 어렵다면 직접 확인받는다. |

## 2. 숫자 입력과 부채비율 계산

| 입력 | 단위 | 어디서 보나 |
|---|---|---|
| 내 보증금 | 만원 | 계약 예정 금액 |
| 매매 시세 | 만원 | 국토부 실거래가 공개시스템, KB부동산, 안심전세 앱 (MVP는 직접 입력) |
| 채권최고액 | 만원 | 을구 근저당권 줄 (`B1_MORTGAGE`가 "예"일 때만, 여러 개면 합계) |
| 선순위 보증금 | 만원 | 다가구주택이면 나보다 먼저 들어온 세입자 보증금 합계. **등기부에 안 나와서** 중개사에게 물어봐야 함. 모르면 0 + 경고 |

```
부채비율 = (채권최고액 + 선순위 보증금 + 내 보증금) ÷ 매매 시세 × 100
```

| 부채비율 | 점수 | 쉬운 설명 |
|---|---|---|
| 90% 이상 | +40 | 집을 팔아도 내 보증금을 다 못 돌려받을 수 있는 "깡통전세" 수준 |
| 80% 이상 ~ 90% 미만 | +25 | 집값이 조금만 떨어져도 위험 |
| 70% 이상 ~ 80% 미만 | +10 | 여유가 크지 않음 |
| 70% 미만 | 0 | |

## 3. 등급

| 합계 점수 | 등급 | 화면 문구 |
|---|---|---|
| 0~29 | 🟢 `SAFE` 안전 | 큰 위험 신호는 없어요. 그래도 잔금일에 등기부를 한 번 더 확인하세요 |
| 30~59 | 🟡 `CAUTION` 주의 | 확인이 필요한 항목이 있어요. 아래 질문을 중개사에게 꼭 물어보세요 |
| 60 이상 | 🔴 `DANGER` 위험 | 계약을 다시 생각해 보세요. 전문가 상담을 권해요 (안심전세 앱 무료 법률상담) |

- `+60` 항목은 **하나만 있어도 바로 🔴**가 되도록 일부러 60으로 맞춤
- 🟢이어도 "안전 보장"이 아니라는 문구를 같이 보여준다

## 4. 위험 항목별 행동 안내 (AI 실패 시 템플릿)

AI는 아래 내용을 사용자 상황에 맞게 쉬운 말로 다시 써주는 역할만 한다. AI 호출이 실패하면 이 문장을 그대로 보여준다.

결과 화면 제목(`factor_title`)은 이렇게 쓴다: `T1` 주소 불일치 / `T2` 주택이 아닌 용도 / `A1` 집주인과 소유자가 다름 / `A2` 최근 3개월 안에 집주인 변경 / `A3` 신탁 등기 / `A4` 압류·가처분 등 권리 문제 / `B1` 근저당권 있음 / `B2` 이전 세입자 임차권등기 / `B3` 다른 사람의 전세권 / `R1` 위반건축물 / `DEBT_RATIO` 부채비율 ○○%.
"(특약으로 해결하기 어려움)" 항목은 API에서 `specialClause: null`로 보내고, 화면에는 "계약 보류를 권해요"를 보여준다.

| 코드 | 중개사에게 물어볼 질문 | 특약 문구 예시 |
|---|---|---|
| `DEBT_RATIO` | 이 집 매매 시세가 얼마인지, 근거(실거래가)를 보여주실 수 있나요? | 전세보증금반환보증 가입이 거절될 경우 본 계약은 무효로 하며, 임대인은 받은 계약금을 즉시 반환한다. |
| `T1_ADDRESS` | 계약할 집의 정확한 동·호수가 어떻게 되나요? | (특약으로 해결하기 어려움 → 맞는 등기부로 다시 점검) |
| `T2_USAGE` | 이 건물 용도가 주택이 아닌데, 전세보증보험 가입이 되나요? | 전세보증금반환보증 가입이 거절될 경우 본 계약은 무효로 하며, 임대인은 받은 계약금을 즉시 반환한다. |
| `A1_OWNER` | 계약하시는 분이 등기부상 소유자 본인인가요? 대리인이면 위임장과 인감증명서를 보여주실 수 있나요? | 계약금·잔금은 등기부상 소유자 명의 계좌로만 지급한다. |
| `A2_RECENT_OWNER` | 최근에 집주인이 바뀌었는데, 매매와 전세 계약이 동시에 진행되는 건가요? | 임대인은 잔금일 다음 날까지 소유권을 이전하지 않으며, 위반 시 임차인은 계약을 해제할 수 있다. |
| `A3_TRUST` | 신탁회사(수탁자)의 임대 동의서를 받을 수 있나요? 신탁원부도 보여주세요. | 임대인은 신탁회사의 임대 동의서를 계약서에 첨부하며, 동의서가 없으면 본 계약은 무효로 한다. |
| `A4_SEIZURE` | 갑구에 있는 압류(가압류 등)는 언제, 어떻게 정리되나요? | (특약으로 해결하기 어려움 → 계약 보류 권장) |
| `B1_MORTGAGE` | 근저당 채권최고액이 얼마이고, 잔금일에 갚고 말소해 주실 수 있나요? | 임대인은 잔금 지급과 동시에 을구의 근저당권을 말소하며, 말소되지 않으면 임차인은 계약을 해제하고 계약금 반환을 청구할 수 있다. |
| `B2_LEASE_REG` | 이전 세입자가 보증금을 못 받아 임차권등기를 한 건가요? | (특약으로 해결하기 어려움 → 계약 보류 권장) |
| `B3_JEONSE_RIGHT` | 이전 세입자의 전세권은 언제 말소되나요? | 임대인은 잔금일까지 을구의 기존 전세권을 말소한다. |
| `R1_VIOLATION` | 위반건축물인데 전세대출과 보증보험이 가능한가요? | 전세자금대출 또는 보증보험이 불가할 경우 본 계약은 무효로 하며, 임대인은 계약금을 즉시 반환한다. |
| (공통) | 국세·지방세 체납은 없으신가요? | 임대인은 잔금일 다음 날까지 등기부상 권리관계를 현재 상태로 유지하며, 근저당권 등 새로운 권리를 설정하지 않는다. 위반 시 임차인은 계약을 해제할 수 있고 임대인은 손해를 배상한다. |

> 특약 문구는 흔히 쓰이는 표현을 참고한 예시야. 실제 계약에서는 공인중개사와 문구를 확인해야 해 (발표 Q&A에서도 이렇게 답하자).

## 5. 데모용 예시 (계산 검증)

| 케이스 | 입력 | 계산 | 결과 |
|---|---|---|---|
| A. 깨끗한 아파트 | 보증금 2억, 시세 3억, 근저당 없음, 모든 질문 "안전한 답" | 부채비율 66.7% → 0 | **0점 🟢** |
| B. 근생 깡통 빌라 | 보증금 2억 4천, 시세 2억 8천, 채권최고액 3,600만, 용도 "근린생활시설", 최근 소유자 변경 | 부채비율 (3600+24000)÷28000 = 98.6% → +40, `T2` +20, `A2` +10 | **70점 🔴** |
| C. 신탁 오피스텔 | 보증금 1억 5천, 시세 2억, 근저당 없음, 갑구에 "신탁" | 부채비율 75% → +10, `A3` +30 | **40점 🟡** |

케이스 B를 발표 데모 메인으로 쓰면 "위험 → 이유 → 해야 할 일" 흐름을 다 보여줄 수 있어.
